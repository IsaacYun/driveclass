# 시연 영상

[`weareone_DriveClass_demo.mp4`](weareone_DriveClass_demo.mp4) (1분 28초, 1920×1080)

Pleos Connect 에뮬레이터(2560×1440) 화면을 녹화하고, 남성 설명 음성·앱 소리·BGM을 얹었습니다.

- **설명 음성**: 합성 음성(남성, 한국어) 9문장
- **앱 소리**: 앱이 실제로 재생하는 강의 오디오(`assets/blocks/core1.mp3`)와 문장 오디오(`assets/sentences/`). 에뮬레이터 녹화는 소리를 담지 못해 같은 파일을 탭한 시점에 맞춰 넣었습니다.
- **BGM**: 연주곡. 말소리가 나는 동안 자동으로 줄어듭니다.
- 설명 음성과 앱 소리는 **서로 겹치지 않게** 번갈아 배치했습니다. 왼쪽 자막이 검은색이면 설명, 파란색이면 앱 소리입니다.
